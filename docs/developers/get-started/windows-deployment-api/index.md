# Test the Deployment API on Windows

Use the local V2 sandbox to submit and inspect a deployment record. This workflow validates the REST contract; it does not build an image or deploy to a real Kubernetes cluster.

## Steps

1. [Prepare a service request](./01-prepare-service-request.md).
2. [Submit the deployment](./02-submit-deployment.md).
3. [Verify the deployment](./03-verify-deployment.md).

Use bearer token `demo-token` for every request.
