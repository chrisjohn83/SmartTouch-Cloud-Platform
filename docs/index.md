# SmartTouch Cloud Platform

SmartTouch Cloud Platform helps teams build, connect, and deploy IoT-enabled digital experiences. It gives developers the tools to integrate devices, APIs, services, and secure application configuration.

Use this documentation to learn the platform, complete onboarding, build your first integration, and move confidently into production operations.

## What's SmartTouch?

SmartTouch is a cloud platform for connected device and IoT service development. It provides a common foundation for:

- Device connectivity and onboarding
- Secure API authentication
- API exploration and testing
- IoT service deployment
- Local development setup
- Secrets and configuration management

## Build With Platform Features

Developers can use SmartTouch to:

- Build secure API integrations
- Connect and validate devices
- Test API calls before writing production code
- Run services locally during development
- Configure secrets for applications and services
- Resolve common onboarding and integration issues
